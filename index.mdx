Install only the packages you need and wire them together with clean abstractions.

## What is MASA Framework?

MASA Framework is organized around two layers:

- **BuildingBlocks** — Abstract interfaces and base classes defining the contracts for each capability (caching, events, configuration, etc.)
- **Contrib** — Concrete implementations using popular libraries like EF Core, Redis, Dapr, and Hangfire

This separation means you can swap implementations without changing your domain logic. Every building block is an independent NuGet package — add only what your service needs.

## Getting Started

<Steps>
  <Step title="Install .NET SDK">
    MASA Framework requires [.NET 6.0 SDK](https://dotnet.microsoft.com/en-us/download/dotnet/6.0) or later.
  </Step>
  <Step title="Install the project template">
    ```bash
    dotnet new --install Masa.Template
    ```
  </Step>
  <Step title="Create a new project">
    ```bash
    dotnet new masafx -o MyMicroservice
    cd MyMicroservice
    ```
  </Step>
  <Step title="Run the service">
    ```bash
    dotnet run
    ```
  </Step>
</Steps>

<Note>
  For a full walkthrough including package installation and a working event handler, see the [Quickstart guide](/quickstart).
</Note>
